# dotfiles

Configs for **kitty**, **tmux**, **neovim** and **fish**.

Your home directory holds symlinks that point back into this repo. Editing `~/.config/nvim/...` edits the repo, so you can commit straight from here.

| Config | Lives in repo at | Symlinked to |
|--------|------------------|--------------|
| kitty  | `kitty/`         | `~/.config/kitty` |
| tmux   | `.tmux.conf`     | `~/.tmux.conf` |
| neovim | `nvim/`          | `~/.config/nvim` |
| fish   | `fish/`          | *(not linked by `install.sh` yet; link it to `~/.config/fish` by hand)* |

## Setting up a new machine

```bash
# 1. System packages (Arch)
sudo pacman -S --needed git kitty tmux neovim fish ttf-hack \
    base-devel nodejs npm ripgrep lazygit xclip wl-clipboard

# 2. Clone and run the installer
mkdir -p ~/00-system && cd ~/00-system
git clone git@github.com:kashishkebab9/dotfiles.git
cd dotfiles && ./install.sh
```

`install.sh` is safe to run again. It does the following:
1. Symlinks the kitty, tmux and nvim configs. An existing real config is moved to `*.bak.<timestamp>` first, and an empty directory is just replaced.
2. Clones **tpm** into `~/.tmux/plugins/tpm` and installs the tmux plugins (if tmux is installed).
3. Clones **packer.nvim** and runs `:PackerSync` headless to install every nvim plugin.

### Why each package is needed
- `fish`: kitty starts `/usr/bin/fish` (`shell` in `kitty.conf`). **kitty won't open a shell without it.**
- `ttf-hack`: the kitty font.
- `base-devel` (gcc): treesitter compiles its parsers with a C compiler.
- `nodejs`/`npm`: coc.nvim runs on node.
- `ripgrep`: Telescope's grep (`<leader>ps`).
- `lazygit`: lazygit.nvim.
- `xclip`/`wl-clipboard`: clipboard for tmux copy-mode and nvim's `clipboard=unnamedplus`. The tmux `y` binding calls `xclip`. On Wayland, `wl-copy` is the native tool.

## After install

- **tmux**: start tmux and press `prefix + I` to (re)install plugins. Use `prefix + U` to update them.
- **nvim**: run `:PackerSync` after you add or remove anything in `nvim/lua/kash/packer.lua`. Run `:Mason` to install LSP servers and `:TSUpdate` to update parsers.
- **kitty**: `ctrl+shift+F5` reloads the config.

## Cheat sheet

### tmux (prefix = `Ctrl-a`)
| Keys | Action |
|------|--------|
| `prefix -` | split side by side |
| `prefix =` | split top/bottom |
| `Alt-←↑→↓` | move between panes (no prefix) |
| `prefix [` | copy mode (vi keys: `v` select, `V` line, `y` yank to clipboard) |

Mouse is on.

### neovim (leader = `Space`)
| Keys | Action |
|------|--------|
| `Ctrl-p` | find files (Telescope) |
| `<leader>ps` | grep the project |
| `Ctrl-b` | toggle Fern file drawer |
| `<leader>pv` | netrw explorer |
| `<leader>u` | undotree |
| `<leader>gs` | git status (fugitive) |
| `<leader>w` | toggle line wrap |
| `Ctrl-t` | new tab |
| `gd` / `K` / `<leader>vrn` | LSP: definition / hover / rename |

### nvim layout
```
nvim/
  init.lua                 # entry point: require("kash") + editor options
  lua/kash/init.lua        # loads remaps, plugins, per-plugin configs
  lua/kash/packer.lua      # plugin list
  lua/kash/remap.lua       # global keymaps
  lua/kash/after/plugin/   # one file per plugin config
  coc-settings.json
  plugin/packer_compiled.lua  # generated by packer; changes on every sync
```

## Notes / known quirks
- `nvim/plugin/packer_compiled.lua` is generated and contains absolute paths, so it shows up as modified after every `:PackerSync`. Commit it or `git checkout` it, either is fine.
- packer.nvim is no longer maintained. It still works on nvim 0.12 but prints `vim.tbl_islist is deprecated` warnings. Migrating to lazy.nvim is the long-term fix.
- `ros-nvim.lua` exists but isn't loaded from `lua/kash/init.lua` (and it has syntax errors). ROS is set up through packer's `config` for `ros-nvim` instead.
